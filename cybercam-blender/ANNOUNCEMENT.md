cybercam-blender is a deterministic, testable Blender pipeline for assembling and rendering modular assets — built to scale, automate, and integrate.

What started as a camera model became a system:
- Parametric assembly (anchors, parts, screw patterns)
- Reproducible renders (preview/final presets)
- Headless-friendly CLI
- Unit tests + gated E2E smoke tests with real Blender
- Clear contracts for artists and integrators

This project deliberately prioritizes determinism over aesthetics.
Visual polish comes next — reliability comes first.

This release is just the warm-up.

## Release Summary (v0.3 — Warm-Up)
This release marks the end of the warm-up phase.

What began as a Blender asset evolved into a **deterministic, testable pipeline** for assembling and rendering modular objects:

* Parametric assembly via anchors and part catalogs
* Multiple screw placement patterns (radial, linear, grid)
* Reproducible turntable renders with `preview` and `final` presets
* Headless-friendly CLI workflow
* Unit tests and gated E2E smoke tests with real Blender
* Clear documentation and explicit contracts for artists and integrators

This project deliberately prioritizes **determinism over aesthetics**.
Visual polish comes next — reliability comes first.

The system is now sealed, documented, and ready to scale.

> This release is just the warm-up.
